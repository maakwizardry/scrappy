02 Enrich workerUSA.js

Continuous queue loop (poll every 5s, 30s idle, 10s on error). No-website rows get heuristic pain-point tags (no_website, needs_booking_system); a website first runs validateUrl() to catch dead/parked/social-redirect domains, then performEnrichment() scrapes CMS, SSL, contact page, testimonials, and a lead score.

03 Booking outreach bookingOutreachUSA.js

Continuous queue loop (5s after success for rate-limiting, 30s idle, 10s on error). Pulls one qualified cleaning-service lead at a time, creates a provider via the booking API, picks 1 of 3 message templates at random, and assembles a 3-paragraph email with the provider's booking link, a Calendly CTA, and a fixed signature block.

Uses bookingApiClient.js — retry w/ backoff, 2s pacing
External API POST letsbook.maakhq.com/api/providers → provider + templates
Static link calendly.com/workwithmaak — embedded in email copy only
